# Referral Reference Code

**Stage:** 10  
**Status:** PROVISIONAL — REVIEW BEFORE PILOT DEPLOYMENT

## Format

`NCR-XXXXXXXX` where `XXXXXXXX` is the last 8 hex characters of the referral UUID (uppercase).

## Notes

- Local convenience label only.
- Not a security token and not suitable for QR payloads.
- May be replaced by a facility-issued code in a future stage.
