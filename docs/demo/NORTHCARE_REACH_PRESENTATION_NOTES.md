## Slide 1 — The access gap

- Frontline workers have an offline-first app  
- Many households still use basic phones  
- Smartphone-only entry leaves families outside care coordination  

## Slide 2 — NorthCare Reach

- Hackathon extension on NorthCare AI  
- Simulated USSD → community request → worker response  
- Tagline context: Smarter care. Stronger communities.  

## Slide 3 — How the system works

- Basic phone (simulated today)  
- Public Reach API (development-gated)  
- Profession routing  
- Worker Community Requests Centre  
- Privacy-safe public status  

## Slide 4 — Routine community request

- Child health / pregnancy / nutrition / CHPS  
- Reference + one-time PIN  
- Worker acknowledge → contact → handled  
- Handled ≠ clinical care completed  

## Slide 5 — Emergency coordination simulation

- Call 112 first  
- Synthetic request for urgent human review  
- Escalate for further human support  
- No ambulance contacted or dispatched  

## Slide 6 — Why it is context-aware

- Northern Ghana frontline reality  
- Profession ≠ system role  
- Facility-scoped deterministic routing  
- Offline-first clinical core preserved
