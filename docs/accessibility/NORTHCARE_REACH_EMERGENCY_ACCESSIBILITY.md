# NorthCare Reach — Emergency Accessibility (R5)

**Last updated:** 2026-08-03  

## Requirements

- Emergency request text is announced (not colour-only)
- Simulation banner has a combined accessibility label (announced once, not looping)
- Call-112 reminder is included in the banner label
- Escalate button has a clear label and hint (no ambulance)
- Confirmation Cancel vs Escalate request are distinguishable
- Success / error states use polite live region or alerts
- Status remains text + chip
- Large text wraps; touch targets remain ≥ 48dp
- Reduced motion: no flashing or pulsing emergency animation

## Not in R5

- TalkBack interruption loops for emergency banners
- Sound / vibration alerts
- Flashing content
