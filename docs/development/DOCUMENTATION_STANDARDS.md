# Documentation Standards

**Purpose:** How NorthCare AI docs are written and maintained.  
**Status:** Active  
**Last reviewed:** 2026-08-02  

## Rules

- Use descriptive uppercase filenames for major planning documents.  
- Use Markdown.  
- Begin every major doc with purpose and status.  
- Include last-reviewed date.  
- Mark assumptions and unresolved decisions explicitly.  
- Do not duplicate authoritative information — link to the source of truth.  
- Update affected documentation in the same stage as code/structure changes.  
- Do not claim features are implemented when only designed.  
- Use Mermaid diagrams where helpful.  
- Keep secrets and real patient data out of documentation.
