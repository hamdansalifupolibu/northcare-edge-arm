# Risk Result Override Policy

**Status:** MANUAL PRIORITY OVERRIDE DEFERRED — GOVERNANCE REQUIRED

Workers must **not** casually downgrade:

- RED → AMBER  
- RED → GREEN  
- AMBER → GREEN  

via an ordinary control.

## Preferred MVP path

1. Correct source screening information  
2. Record missing information  
3. Recalculate (creates a new version; preserves history)  
4. Continue to future referral workflow (Stage 10)

## Before implementing override

Define required reason codes, authorisation, dual control if needed, and audit behaviour. Do not code override until this policy is approved.
