# Clinical Rule Review Process

1. Author draft pack with source references  
2. Status → `CLINICAL_REVIEW_REQUIRED`  
3. Clinical reviewer validates conditions, thresholds, explanations, languages  
4. Record reviewer identity and review date only when real  
5. Promote to `APPROVED_FOR_PILOT` only after documented approval  
6. Retire superseded versions without mutating historical assessments  

**Current gap:** zero NorthCare AI danger-sign packs are approved for pilot. Synthetic development packs must remain visibly non-clinical.
