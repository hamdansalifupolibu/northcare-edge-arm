# GREEN Result Policy

GREEN must **never** be produced merely because:

- No RED/AMBER rule matched  
- Questions were unanswered / unknown / not assessed  
- Content was unavailable  
- Evaluation failed  

GREEN requires:

1. Explicit matched green rule from an approved pack  
2. Completeness policy satisfied  
3. No blocking missing information  
4. Aggregation strategy permits GREEN  

Otherwise return **undetermined**. Dedicated automated tests enforce this.
