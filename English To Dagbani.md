# English → Dagbanli Translation Verification Sheet

**Project:** NorthCare AI (mobile health worker app)  
**Purpose:** Review and correct Dagbanli UI translations before clinical use  
**Prepared for:** Medical student reviewer (Tamale / native Dagbanli speaker)  
**Date:** 2026-08-07  
**Status:** All translations below are **NOT YET REVIEWED**

---

## Instructions for reviewer

1. Read the **English** phrase (what workers see in English mode).
2. Read the **Current app translation** (what the app shows today in Dagbanli mode).
3. If correct, write **OK** in the **Corrected translation** column.
4. If wrong or awkward, write the **correct Dagbanli** in that column.
5. Add brief **Notes** if needed (e.g. "too formal", "wrong word for child", "keep English acronym").
6. Return this file with your corrections so we can update the app.

**Important:**
- These are **UI labels and buttons** only — not full clinical protocols.
- Keep medical acronyms if standard locally: **SAM**, **MAM**, **MUAC**, **QR**.
- Do **not** invent clinical advice — only fix language/word choice.
- Dagbanli may also be written **Dagbani** — use the spelling you prefer in corrections.
