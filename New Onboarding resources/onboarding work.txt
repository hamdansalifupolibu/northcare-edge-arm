
The photograph remains perceptible behind it, but the title and paragraph have reliable contrast.

The QR image is warm.

The Voice/AI image is indoor and slightly darker.

The USSD image is bright daylight.

The Ghana/offline image has a pale sky.

The gradient **normalizes all five visually** and makes them feel like one deliberate collection.

# Full-screen image behaviour

This is another thing we should lock before implementation.

All five should use something equivalent to:

```tsx
<ImageBackground
  source={...}
  resizeMode="cover"
  style={styles.background}
/>
```

Not:

```text
contain
```

because `contain` can produce blank space.

The image should always cover:

```text
100% screen width
100% screen height
```

and the UI sits above it.

However, we need to define **focal positioning per image** because `cover` inevitably crops slightly on different screen ratios.

For example, the important faces in slide 1 need to remain visible.

The Ghana map in slide 2 must not disappear above the screen.

The Voice-to-Care microphone visuals need to remain visible.

Both QR phones must survive cropping.

The basic feature phone must survive cropping.

So we should not use one blindly identical crop position. We can give each asset a slightly different focal alignment while keeping the overall component reusable.
